🎓 Portal 3AII

Sistema completo para facilitar a vida acadêmica da nossa turma

Funcionalidades Implementadas

Dashboard

Página inicial com resumo das atividades, avisos, enquetes e próximos eventos.

Notas & Médias

Simulador de média por disciplina e calculadora "quanto falta pra passar".

Agenda & Tarefas

Calendário unificado e sistema de tarefas estilo kanban.

Materiais

Biblioteca de PDFs, slides e links organizados por professor.

Professores

Diretório com contatos, horários de atendimento e monitorias.

Vida no Campus

Horários das aulas e achados & perdidos com fotos.

Painel Admin Acessar Portal
Como usar:
  1. Configure o arquivo .env com suas credenciais MySQL
  2. Execute python manage.py migrate
  3. Crie um superusuário com python manage.py createsuperuser
  4. Execute python manage.py runserver
  5. Acesse http://localhost:8000
